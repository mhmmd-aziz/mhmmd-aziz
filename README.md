## 👋 About Me

I'm **Muhammad Aziz**, an Informatics Engineering student at
**Politeknik Negeri Lhokseumawe, Indonesia**, with hands-on experience
in full-stack web development, AI/ML, computer vision, IoT, mobile
applications, and system administration.

I enjoy taking ideas from development to deployment---building
responsive web applications, machine-learning prototypes, data
dashboards, and connected systems that address real-world problems.

-   💻 **Web development:** responsive interfaces, backend services,
    REST APIs, and database integration.
-   🧠 **AI & machine learning:** deep learning, computer vision, NLP,
    sentiment analysis, and predictive models.

    real-time monitoring.

    server administration.
